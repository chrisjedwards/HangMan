# Video Script Outline

Target length: 5-6 minutes. The assignment minimum is 4 minutes. The recording will be in English.

## 1. Introduction and purpose (0:00-0:40) - Gaby

Introduce AI Hangman, the programming and technology theme, the school GenAI assignment, and the goal of deploying a playable public web application.

## 2. Phase 1 research (0:40-1:30) - Chris

Explain the AWS Bedrock research, the choice of Flask and plain JavaScript, the EC2/Nginx architecture, cost planning, and expected risks.

## 3. Phase 2 implementation (1:30-2:30) - Chris

Walk through the backend structure, server-side game state, three API endpoints for AI tasks, prompt templates, validation, fallback words, mock mode, and the API contract.

## 4. Live demo (2:30-4:20) - Gaby

Show the frontend, choose a category and difficulty, play a game, request a hint, make guesses, and show the final AI comment. Demonstrate the public link and explain that the secret word is hidden until game over.

## 5. Phase 3 finalization and AWS deployment (4:20-5:10) - Chris

Show the Terraform/cloud-init plan, Nginx proxy arrangement, Gunicorn systemd service, environment configuration, and the deployed public IP or link.

## 6. Problems and solutions (5:10-5:40) - Chris and Gaby

Briefly explain the AWS cost incident, Billing permissions issue, and Bedrock account verification issue, using the real devlog entries.

## 7. Conclusion (5:40-6:00) - Gaby

Summarize what was achieved, what was learned, and one improvement for future work.

## Recording checklist

- [ ] OBS or Loom selected
- [ ] Clear audio
- [ ] Readable screen and browser zoom
- [ ] English narration
- [ ] Calm pace
- [ ] Show real code and results
- [ ] Keep the recording above four minutes
